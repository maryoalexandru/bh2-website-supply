# BH2 SUPPLY — Merch Store Demo

A responsive streetwear storefront concept made with HTML, CSS, and vanilla JavaScript. No build tools are needed.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait a minute or two for your public Pages URL.

## Customize
- Brand name and page text: `index.html`
- Colors and layout: `style.css`
- Product names, prices, categories and labels: the `products` array at the top of `script.js`
- Currency: change the `euro()` function in `script.js`

## Important
This is a demo storefront. Product filtering and the browser cart work, but it does not store orders or process payments. The newsletter form does not send or save email addresses. For real sales, connect a reputable e-commerce/payment provider and configure shipping, returns, privacy and tax details. Use only product photos and brand assets you have permission to use.
